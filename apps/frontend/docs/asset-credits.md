# Frontend visual assets

- `public/visuals/hero-fire.mp4` is the 720p version of [Firewood burning in a campfire](https://mixkit.co/free-stock-video/firewood-burning-in-a-campfire-42768/) from Mixkit. It is used under the [Mixkit Stock Video Free License](https://mixkit.co/license/modal/videoFree/).
- `public/visuals/hero-fire-poster.webp` is a still frame extracted from that clip for loading and reduced-motion presentation.

The landing page labels the clip as atmosphere. It is not presented as NASA experimental footage or evidence.
